# ☕ Java Programming for Beginners

A beginner-friendly Java programming repository containing practical exercises, coding solutions, learning notes and examples developed while following the **Java Programming for Beginners** learning pathway on CodeSignal platform. This repository serves as my personal learning workspace and coding portfolio documenting my progress in learning Java, strengthening programming fundamentals and developing problem-solving skills through hands-on practice.

## 📌 About the Repository

The **Java Programming for Beginners** repository is dedicated to learning and practising Java programming from the ground up. It contains code implementations, practice exercises, solutions and other learning materials related to the CodeSignal Java learning pathway. The main objective is to build a strong foundation in Java programming by understanding fundamental concepts, writing code, solving programming challenges and applying theoretical knowledge through practical exercises.

## 🎯 Learning Objectives

Through this learning pathway, I aim to:

- Understand the fundamentals of Java programming.
- Learn Java syntax and programming conventions.
- Develop the ability to write, compile and execute Java programs.
- Understand variables, data types, operators and expressions.
- Develop logical thinking and problem-solving skills.
- Practise solving programming challenges independently.
- Build confidence in writing clean and understandable Java code.
- Establish a strong foundation for advanced Java concepts and Object-Oriented Programming (OOP).

## 🛠️ Requirements

To run the Java programs in this repository, you will need:

- Java Development Kit (JDK).
- A Java-compatible IDE or code editor.
- Git (optional, for cloning the repository).
- A command-line terminal.

## ▶️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Nipun-Lakshan/java-programming-for-beginners-course.git
```

### 2. Navigate to the Repository

```bash
cd java-programming-for-beginners-course
```

### 3. Open the Project

Open the repository using IntelliJ IDEA, Visual Studio Code or your preferred Java development environment.

### 4. Compile and Run a Java Program

Navigate to the directory containing the Java source file.
